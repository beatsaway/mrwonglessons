Project modules · KS3 & 4

How students use these modules

Every student starts from a shared foundation (micro:bit, basic I/O, preset builds). They then pick and combine elements from the categories below to shape their own rover project.

The more categories used, the more complex the build. Students can stay on guided presets or extend with custom sensors, outputs, mechanics, and mission goals.

Projects follow three progression stages across KS3 & 4 — remote control, then sensing & autonomy, then payload & coordination — without being locked to a single school year.

Difficulty levels (optional add-ons)

  1. Preset logic — e.g. LED on when temperature crosses a threshold
  2. Preset rover chassis — standard car build
  3. Custom sensor choice — students map inputs to their sub-problem
  4. Custom mechanics — LEGO joints, gears, cams, 3D-printed tools
  5. Stretch — Arduino, lander deployment, multi-rover coordination

Reference kits (all stages): Yahboom WOM sensor kit · Yahboom Superkit building blocks

Foundation stage · remote manoeuvring

Entry level (typically KS3): the micro:bit controls a rover in a simulation. Choose an input module and an IDE option.

Example project combinations

  • Buttons → drive rover in Three.js sim
  • Phone tilt (pitch / roll) → steer on moon surface
  • Hand gestures → turn or speed changes
  • Sound level → jump or dash
  • Piano or guitar notes → different movements per pitch
  • Chopstick or fidget spinner → custom steering interface
  • Proximity sensor → avoid obstacles while driving

Intermediate stage · sensing & autonomy

Building on foundations (KS3–4): a real micro:bit rover reads the environment and moves on its own.

Example project combinations

  • Temperature → seek or avoid hot / cold zones
  • Light sensor → seek brightness or avoid darkness
  • Compass / location → navigate to assigned points
  • Ultrasound + tilt → bumpy ground; avoid steep slopes
  • Temperature / IR → detect cool regions (water-ice scout proxy)
  • Battery monitor → return to base when low

Inputs: on-board sensors Outputs: motors + LEDs Mechanics: preset chassis

Advanced stage · payload & coordination

Extended projects (KS3–4): move resources from A to B; tools and two or more rovers working together.

Example project combinations

  • Crane / grabber → lift brick-like blocks
  • Suction straw → collect liquid sample
  • Spoon / scoop → pick up regolith
  • Cargo box → deliver goods to a drop zone
  • Radio signal → call a partner rover to rendezvous
  • Exchange tray → swap cargo between two rovers
